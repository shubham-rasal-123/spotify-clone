# Spotify Clone

A Spotify-inspired music player interface built with plain HTML, CSS, and JavaScript.

![Spotify Clone Preview](images/Screenshot%20from%202024-11-10%2015-59-39.png)

## Description

This project recreates the look and feel of a Spotify-style music streaming UI. It includes a sidebar navigation, album artwork, a now-playing section, and playback controls for interacting with songs.

The interface is designed to practice front-end development skills such as:

- responsive layout design
- component-based UI structure
- JavaScript event handling
- interactive music player controls

## Tech Stack

- HTML
- CSS
- JavaScript

## Features

- Spotify-inspired layout
- Responsive music player interface
- Play, pause, and track navigation controls
- Smooth interactive UI experience

## Run Locally

1. Clone the repository.
2. Open the project folder.
3. Start a local server:

   ```bash
   python3 -m http.server 8000
   ```

4. Open your browser and visit:

   ```text
   http://localhost:8000
   ```

## Notes

This project is a front-end practice project and does not require any build tools or dependencies.
