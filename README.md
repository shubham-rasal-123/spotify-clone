## ✨ Overview

This project recreates the look and feel of a Spotify-style music streaming UI with a clean, modern layout. It includes a sidebar navigation, album artwork, a now-playing section, and playback controls for interacting with songs.

The goal of this project is to practice front-end development fundamentals such as:

- responsive layout design
- structured UI composition
- JavaScript event handling
- interactive music player controls

## 🎵 Features

- Spotify-inspired user interface
- Responsive music player layout
- Play, pause, and track navigation controls
- Smooth and interactive UI experience
- Lightweight static frontend with no build setup required

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## ▶️ Run Locally

1. Clone the repository.
2. Open the project folder.
3. Start a local server:

   ```bash
   python3 -m http.server 8000
   ```

4. Visit the app in your browser:

   ```text
   http://localhost:8000
   ```
